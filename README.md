# just4kit
#### by Chamith Hirusha

**Upscale AI-generated videos to 4K 60 FPS, strip tracking metadata, and auto-generate SEO tags — 100% free, local, and privacy-first.**

---

## Why I Built This
* **Free Local Processing:** High-quality AI video upscaling and frame interpolation services are locked behind expensive subscriptions. This tool brings that power straight to your local machine.
* **Bypass Automated AI Tags:** Social media platforms scan video metadata to apply "AI-generated" tags automatically. **just4kit** completely strips existing metadata to keep your uploads clean.
* **Streamlined Publishing:** Managing multi-platform metadata takes time. The script prompts you for titles and descriptions, then bakes customized metadata directly into your output files.

---

## Quick Start Guide (macOS)

> **Note:** Currently tailored for **macOS Terminal**. A cross-platform desktop application with a full GUI is actively in development!

1. **Download:** Get the `convert.sh` script.
2. **Organize:** Create a new folder containing **only** the video files you want to process.
3. **Move Script:** Copy `convert.sh` directly into your video folder.
4. **Run:** Open **Terminal**, navigate to your folder (`cd path/to/folder`), and execute:
   ```bash
   zsh convert.sh
   ```
5. **Follow Prompts:** Input your desired title patterns, video numbering, and SEO metadata when prompted.
